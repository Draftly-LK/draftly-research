# Required Textbooks

## Purpose

The curriculum lists textbooks for study. These are likely copyrighted works,
so Draftly records bibliographic references and availability notes instead of
downloading unauthorized copies.

## Handling Rule

Only add full text if the team has a lawful copy and permission to store it in
the project dataset. Otherwise, store reading notes, page references, and
lawyer-authored summaries separately from the source library.
