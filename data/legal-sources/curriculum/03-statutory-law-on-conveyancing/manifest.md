# Curriculum Section 3: Statutory Law on Conveyancing

## Purpose

This manifest maps the curriculum's Section 3 statutory-law list to Draftly
source IDs. The source registry remains the operational tracker; this file is
the curriculum-facing audit view.

## Coverage Summary

Most Section 3 laws are now either downloaded as standalone PDFs or indexed to
shared legislative volumes already stored in the library. One item is currently
indexed as public HTML only because no clean standalone public PDF was found.
