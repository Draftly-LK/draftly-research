# case-001-property-title-transfer-bundle

## Case Name
Property Title Transfer Bundle

## Description
Single private legal-document case bundle containing conveyancing/title documents,
municipal or assessment records, identity/supporting images, and related lawyer-prepared
outputs.

## Folder Meaning
- `inputs/`: source documents and supporting evidence.
- `target_outputs/`: lawyer-prepared or expected output documents.

## Notes
- This folder contains real legal/personal information and should remain private.
- Do not publish these raw files to GitHub or public demos.
- Create anonymized copies separately before using the case for presentations,
  evaluation, or public examples.
